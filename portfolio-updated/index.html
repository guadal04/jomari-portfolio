TMWE Website & Booking System

Web design · Front-end development · Booking workflow

The Miracle Wedding & Events is a full-service wedding planning and styling team in the Philippines. They needed a website that looks as elegant as their weddings and lets couples pick a package, check available dates and send a booking request without back-and-forth messages.

I designed and built the site end to end: a cinematic photo hero, service and package pages, a step-by-step booking flow with a live availability calendar, and a separate admin dashboard where the team manages every request.

View live demo Admin dashboard Booking tracker
3connected pages: site, admin, tracker
4wedding packages, ₱300K – ₱800K
4 stepsdate → package → customize → details

What I built

  • Animated hero slideshow with a photo-card carousel
  • Package builder with venue choice, guest count and add-ons, plus a live estimated total
  • Availability calendar — booked and blocked dates can't be selected
  • Booking agreement with e-signature, cancellation policy and Data Privacy Act consent
  • Deposit step with GCash, Maya, card and bank-transfer options (demo mode)
  • Client booking tracker and chat, using a reference number
  • Admin dashboard: status filters, sorting, CSV export, date blocking and inbox
  • Filterable photo gallery with lightbox, plus an inquiry form

Tools used

HTML5CSS3Vanilla JavaScriptResponsive designLocalStorageGoogle Fonts

Note

Payments and emails run in demo mode, and the data is stored in the browser. A live launch would move bookings and login to a server — a natural next step with my Laravel background.
